# How I like TODOs done

- One task per line, written as an imperative ("Email the vendor", not "Vendor email").
- Mark a finished item by prefixing it with `[x] `; leave open items with `[ ] `.
- Keep the newest open items at the top; move completed items to a `## Done` section at the bottom.
- Never delete a completed item — moving it to Done is the record that it happened.
- If a line would be longer than one sentence, split it into two tasks instead.
